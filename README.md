# naruto-collector
Naruto Collector for Windows — releases, automatic update feed, and publishing tools.

Get the complete Windows ZIP from [Releases](https://github.com/Abotboot/naruto-collector/releases/latest). Version 93.1.17 adds recovery for Stop during the initial Wanted walk, before any fight was sent. One guarded account-page reload disposes of the old walking callbacks; a fresh server query must confirm the same free accepted mission before normal Auto can resume. The original receipt stays preserved with its outcome unknown, and recovery sends no acceptance, fight or reward claim. It also includes 93.1.16's Wishing Tree protocol-error recovery and initial Hot Topics helper-timeout retry fix. See release notes for qualification and limits.

Extract the full ZIP into one folder. Keep `_internal` and `Naruto Update Helper.exe` beside `Naruto Collector.exe`; Python is not required. See [Quick start](QUICKSTART.md) for game/CDP setup and the one-time upgrade from older clients.

Versions 93.0.0 and later can check this repository's latest release on startup or through Help. Finish the current pass and stop Auto before updating. In-app updates preserve profiles, settings, histories, pending receipts and personal answer banks. Unknown gameplay outcomes still require their original evidence.
